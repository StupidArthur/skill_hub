# 技术路线

这个目录只保存**本仓库有明确偏好的技术决策**。通用框架知识、组件教程、代码片段和固定版本不再维护，由 Agent 根据当前项目与最新生态自行判断。

## 使用原则

### 已有项目

默认沿用项目现有技术栈、架构和组件体系。除非任务本身涉及架构迁移，否则通常不需要继续读取本目录。

### 全新项目

根据产品形态、部署方式、生态能力、团队维护成本和用户约束选择合适方案。能自行判断时直接给出推荐，不要求用户在 Go/Python/React 等常规选项之间替 Agent 做技术决策。

## 本仓库保留的偏好

### 桌面 GUI

优先采用 **Wails + Go** 作为桌面壳和控制层；只有 Python 生态带来明确收益时才增加独立 Python Worker。具体边界见 [gui-tool/README.md](gui-tool/README.md)。

### Web / CLI

不再维护专门的 Go/Python 框架手册。已有项目跟随现状；全新项目根据需求选择当前主流、维护良好的方案即可。

## 不再由 dev-skill 维护的内容

- React / Shadcn / Tailwind 等组件和样式教程；
- Go、Python Web/CLI 框架的基础用法；
- 代码片段库；
- 大型示例工程；
- 固定目录模板和为了分层而分层的架构手册。

这些内容变化快，而且当前 Code Agent 能直接读取项目、官方文档和依赖信息后做出更合适的实现。
